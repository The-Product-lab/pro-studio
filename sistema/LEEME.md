# Pro Studio

Editor de reels que diseña cada video a medida.

1. Windows: clic derecho en el ZIP → **Extraer todo**. Mac: doble clic en el ZIP.
2. Doble clic en **Instalar Pro Studio** (el `.bat` en Windows, el `.command` en Mac). La primera vez baja ~3 GB y puede tardar.
3. Cuando termine se abre la app y queda el icono **Pro Studio** en tu Escritorio.
4. Desde ahí, doble clic en ese icono cada vez que quieras editar.
5. Necesitas una cuenta de Claude con suscripción; el instalador te pide iniciar sesión una vez.
6. Si algo falla, copia el mensaje y mándaselo a Claude: abre esta carpeta con Claude Code y él sabe qué hacer.
